## 残し方

- 各章の `README.md` に、理解したこと・疑問・試した結果を記録する。
- 小さな写経コードは、対応する節番号をファイル名にする（例：`02_io.Writer/2.4.1.go`）。
- 複数ファイルを使う実行例は、節やテーマごとのサブディレクトリにまとめる。
- 演習のコードは、必要になったら各章の `exercises/01/` などへ追加する。
- 実行に必要なOS・コマンド・入力データがあれば、対応する章のREADMEに記録する。

## 実行例

コードを追加したら、リポジトリのルートから対象ファイルを指定して実行する。

```bash
go run ./02_io.Writer/2.4.1.go
```

複数ファイルで構成する例は専用ディレクトリに分ける。Goモジュールが必要になったら、ルートで次を実行する。

```bash
go mod init github.com/kobadaidesu/go_system_programming
```
